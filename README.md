# Linux-server

سرور پایدار Ubuntu مبتنی بر GitHub Actions با **داده‌های ماندگار، کلید SSH ثابت و IP پایدار Tailscale**.

هر بار که سرور منقضی شود (هر ۵.۵ ساعت) یا Workflow به صورت دستی متوقف/مجدداً اجرا شود، تمام اطلاعات، برنامه‌های نصب‌شده و تنظیمات سیستم به طور خودکار و بدون نیاز به دخالت دست بازگردانی می‌شوند.

## ویژگی‌های کلیدی

- **ماندگاری کامل داده‌ها:** ذخیره‌سازی داده‌های شخصی (`/home/Hamid`, `/root`)، تنظیمات سیستم (`/etc`) و برنامه‌ها (`/opt`, `/srv`, `/usr/local`, `/var/www`).
- **پایداری هویت Tailscale:** حفظ وضعیت و هویت Node در Tailscale (`/var/lib/tailscale`) جهت تثبیت نام و آدرس IP سرور در شبکهٔ Tailnet.
- **کلید SSH ثابت:** کلید عمومی `ed25519` ثابت در مخزن و دسترسی همیشگی با همان کلید خصوصی بدون تغییر.
- **مدیریت بدون رمز:** کاربر `Hamid` دارای دسترسی کامل sudo بدون رمز (`sudo su` بدون نیاز به ورود Password).
- **بدون تولید بکاپ اضافی:** مدیریت پایدار Release به صورت Rolling بر روی مخزن `Linux-server-state` (تنها یک آرشیو `state.tar.gz` فعال).
- **مقاوم در برابر Cancel دستی:** در صورت Cancel شدن یا شروع مجدد، آخرین وضعیت به صورت خودکار ذخیره و در چرخه بعدی بازگردانی می‌شود.

---

## نحوه اتصال به سرور

پس از اجرای Workflow، سرور به Tailscale متصل شده و اطلاعات اتصال در لاگ‌ها و Step Summary نمایش داده می‌شود:

```bash
# اتصال با کلید خصوصی SSH:
ssh -i ~/.ssh/id_ed25519 Hamid@<TAILSCALE_IP>

# یا اتصال با MagicDNS (در صورت فعال بودن در Tailnet):
ssh -i ~/.ssh/id_ed25519 Hamid@linux-server-vps
```

- **کاربر:** `Hamid`
- **پورت:** `22`
- **دسترسی Root:** اجرای `sudo su` بدون نیاز به پسورد.

## ساختار ذخیره‌سازی و پایداری

1. **مخزن داده‌ها:** وضعیت سرور در مخزن اختصاصی `Linux-server-state` به صورت یک Release چرخشی نگهداری می‌شود.
2. **شروع Run جدید:** اسکریپت `restore.sh` وضعیت را دانلود کرده، پکیج‌ها و فایل‌ها را در مسیرهای مربوطه مستقر می‌سازد.
3. **پایان Run یا Cancel:** اسکریپت `save.sh` با دستور `if: always()` اجرا شده و آخرین وضعیت را بر روی همان Release جایگزین می‌کند.

برای افزودن هر مسیر جدید جهت پایداری، کافی است مسیر مورد نظر را به فایل `.github/scripts/persist.list` اضافه کنید.

---

## Secrets مورد نیاز در مخزن اصلی

| Secret Name | توضیحات |
|---|---|
| `PERSIST_TOKEN` | توکن دسترسی GitHub Personal Access Token با دسترسی نوشتن به `Linux-server-state` |
| `TAILSCALE_AUTH_KEY` | کلید Auth تیل‌اسکیل برای احراز هویت اولیه سرور |
| `TAILSCALE_API_TOKEN` | (اختیاری) توکن API تیل‌اسکیل جهت پاک‌سازی خودکار Nodeهای مرده و آفلاین |
| `HAMID_PASSWORD` | (اختیاری) پسورد ورود کاربری |

---

## امنیت
- مخازن را در وضعیت **Private** نگهداری کنید.
- کلید خصوصی SSH را هرگز commit نکنید و صرفاً روی سیستم شخصی خود نگه دارید.
- در صورت تغییر کلید SSH، کافی است مقدار کلید عمومی را در `.github/ssh/id_ed25519.pub` قرار دهید.
